# 소액주주 현황 — 법인팀 전달 자료

요청하신 CSV 입니다. `소액주주현황.csv`

## 파일 형태

```
종목코드,소액주주비율,주주수,기준연도
005930,66.04,4195927,2025
```

- `종목코드` — 6자리 보통주 코드. 우선주는 애초에 안 들어 있습니다.
- `소액주주비율` — %, 소수점 둘째 자리. DART `mrhlSttus` 의 `hold_stock_rate`.
- `주주수` — 명. 값이 없으면 빈 칸입니다.
- `기준연도` — 그 값이 실린 사업보고서의 사업연도.

인코딩은 UTF-8, 줄바꿈은 LF, 종목명 정렬입니다.

## 한 가지 짚어둘 것 — 소액주주는 개인투자자가 아닙니다

이름 때문에 개인 비중으로 읽히기 쉬운데, 지분 1% 미만 주주 **전부**입니다.
1% 미만씩 나눠 든 외국계·국내 기관이 여기 다 섞여 있고 국적 구분도 없습니다.

그래서 원형 차트 조각 이름은 「소액주주」 그대로 두시는 편이 안전합니다.
「개인」이라고 적으면 실제와 어긋납니다. (요청서에도 같은 이해가 적혀 있어서
확인차 적어 둡니다.)

## 대주주 조각과 겹치지 않습니다

소액주주는 1% 미만만 세므로 5% 이상 대량보유자와 애초에 겹칠 수 없습니다.
표본으로 확인했을 때 최대주주 + 소액주주 합이 100%를 넘는 종목은 없었습니다.

다만 **외국인 보유비중 조각과는 겹칩니다.** 외국인 비중은 국적 기준이고
소액주주는 지분 크기 기준이라 잣대가 다릅니다. 한 차트에 둘을 같이 놓으면
합이 100을 넘습니다. 저희 화면은 외국인 조각을 쓰고 있어 소액주주는 안 넣었는데,
법인팀에서 소액주주를 쓰신다면 외국인 조각과 택일하시는 게 맞습니다.

## 비율은 저희가 다시 셌습니다

DART 가 주는 `hold_stock_rate` 를 그대로 옮기지 않았습니다. 그 필드는 보고서에
적힌 값을 그대로 실어 주는 것이라 회사가 잘못 적으면 그대로 옵니다.

    온타이드(005320)  hold_stock_rate "100%"
                      같은 행의 보유주식 42,290,297 / 총주식 67,375,690 = 62.8%

그래서 같은 행에 함께 오는 보유주식·총주식으로 다시 계산했습니다. 둘 중 하나가
없을 때만 적힌 비율을 씁니다. 법인팀에서 직접 받아 쓰실 때도 같은 처리를
권합니다.

## 기준 시점

최신 사업보고서 하나만 담았습니다. 직전 사업연도부터 거슬러 올라가며 값이
나오는 첫 해를 씁니다. 반기·분기보고서에는 이 표가 없는 경우가 많고,
분기 사이에 크게 흔들리는 값도 아닙니다.

신규 상장처럼 사업보고서가 아직 없는 종목은 빠져 있습니다.

## 다시 뽑으려면

```
node scripts/theme/collect-minority.mjs        # 수집 (이어서 됨)
node scripts/theme/collect-minority.mjs --csv  # CSV 만 다시 내보내기
```

것으로 CSV 를 냅니다. 다음 날 같은 명령을 다시 치면 이어서 받습니다.
