# 지난 꾸러미와 무엇이 다른가

2026-09-01 기준. **먼저 이 문서를 보고, 바뀐 자리만 다시 받으면 된다.**
나머지는 지난번 그대로다.

여섯 가지인데 뿌리는 둘이다.

  같은 값을 두 곳에 두지 않는다        1 · 5
  같은 값이 두 곳에서 다르면 안 된다   2 · 4
  그 밖에 그냥 틀린 것                 3 · 6

## 1. 종목 개요 → 기업 개요 (설계가 바뀌었다)

### 무엇이 문제였나

지난 꾸러미의 개요 카드는 세 칸이었다.

```
셀트리온 개요
  주요사업  항체 바이오시밀러  특허 만료된 바이오의약품의 복제약
            바이오시밀러 5종목   시총 44.36조
  평가      SIGNO 66점 · 매출25년 +17.01% · 이익률 +28.07% · PER 29.0배
            증권가목표 274,621원 +43.60% · 의견 4.0/5
  모멘텀    1개월 +0.37% · 골든크로스 · 외국인 25.6%
```

이 값이 **하나도 빠짐없이 아래 카드에 또 있다.**

| 개요에 있던 것 | 실제로 있는 곳 |
|---|---|
| SIGNO 점수 · 골든크로스 | 섹터 종합평가 |
| 매출성장 · 영업이익률 | 재무제표 |
| PER · 시총 · 목표주가 · 의견 | 종목 상세 |
| 1개월 · 외국인 | 종목 상세 |
| 테마 N종목 | 차트 위 테마 칩 |

겹치지 않는 것은 사업 설명과 주요사업 낱말 둘뿐이었다. 같은 숫자를 두 번
보여 주느라 정작 **"이게 뭐 하는 회사냐"** 가 숫자에 묻혔다.

차트보다 이 카드를 먼저 두기로 한 이유가 그 물음 때문인데, 정작 그 답이
제일 안 보였다.

### 어떻게 바뀌었나

```
셀트리온 개요
  · 항체 바이오시밀러(특허 만료된 바이오의약품의 복제약)를 개발·생산해
    미국·유럽 등 글로벌 시장에 직접 판매하는 국내 대표 바이오기업이다.
  · 생명공학기술을 기반으로 자가면역질환, 종양 등 질병의 치료에 사용되는
    의약품을 개발 및 상업화하는 것을 주요 목적 사업으로 하는 글로벌
    생명공학기업이다.
  · 2023년 12월 ㈜셀트리온헬스케어와의 합병을 통해 개발, 생산, 판매가
    결합된 통합 법인 체제를 완성했다.
```

문장은 **DART 사업보고서 '사업의 내용 — 사업의 개요' 원문에서 골라 옮긴
것**이다. 지어내지 않는다. 어미만 평서체로 맞추고 뜻은 건드리지 않는다.

증권플러스·네이버의 기업개요도 결국 같은 원문을 줄인 것이라 따로 사 올
것이 없다.

  커버리지  2,497종목 중 2,435종목(97.5%) · 종목당 평균 2.8문장
  없을 때   테마 편입 사유 한 줄로 대신한다(59종목 · 2.4%). 그것도 없으면
            주요사업 낱말만 뜬다(3종목). 카드가 통째로 비는 종목은 없다.
  없을 때   테마 편입 사유 한 줄로 대신하고, 그것도 없으면 카드째 숨는다

### 이 카드는 바깥을 하나도 안 부른다

전에는 여기서 시세·일봉 270개·시장 기준선까지 받았다. 숫자를 걷어낸
뒤로는 아무도 쓰지 않는 값을 받자고 네 군데를 두드리고 있었다.

**300ms → 22ms.** 굳혀 둔 표 둘(`themes.json` · `about.json`)만 읽는다.
코스콤도 DART 도 키도 필요 없다 — **종목탭에서 제일 먼저 붙일 수 있는
카드다.**

### 받는 것

`GET /api/stock-brief?code=068270`

```json
{
  "name": "셀트리온",
  "about": ["…", "…", "…"],
  "why": "항체 바이오시밀러(…)를 개발·생산해 … 국내 대표 바이오기업이다.",
  "biz": ["항체 바이오시밀러", "특허 만료된 바이오의약품의 복제약"]
}
```

지난 꾸러미의 `cap` `score` `growth` `opm` `per` `target` `upside`
`recomm` `ret1m` `cross` `foreign` `themeName` `themeCount` `themeChg`
는 **없어졌다.** 각각을 보여 주는 카드가 따로 받는다.

### 주요사업 낱말은 문장에 없는 것만 남긴다

낱말은 개요 문장에서 뽑아낸 것이라 **99.5%가 문장 안에 그대로 있다.**
바로 위에 쓰인 말을 칩으로 또 다는 것은 군더더기다. 개요가 없어 칩만
서는 종목에서는 다 남긴다.

셀트리온은 낱말 둘이 첫 문장 안에 있어서 칩이 하나도 안 뜬다. 정상이다.

### 문장 새로 만들기 (분기 1회)

```
node scripts/theme/build-about.mjs          몇 건이 서는지만 본다
node scripts/theme/build-about.mjs --write  → src/data/about.json
```

`.cache/theme/overview.json`(DART 원문)이 있어야 한다. 그것을 모으는
법은 `docs/테마탭-인계.md` 의 수집 절차와 같다.

## 2. 주소로 바로 들어오면 이름이 안 떴다

`/stock?code=068270` 처럼 `name` 없이 들어오면 이름 자리에 코드가 그대로
박혔다 — **"068270 개요"**. 링크를 손으로 치거나 남에게 받은 주소에는
`name` 이 대개 빠져 있다.

두 겹으로 채운다.

| 대상 | 방법 |
|---|---|
| 분류표에 있는 종목 2,497개 | 서버에서 `nameOf(code)` — 깜빡임이 없다 |
| 그 밖 약 300개 | `stock-brief` 가 `name` 도 돌려준다 |

첫째 겹이 중요하다. 시세를 받아 이름을 알아내면 제목이 잠깐 "068270"
이었다가 "셀트리온" 으로 바뀐다. `themes.json` 은 배포에 실려 있어 그릴
때 바로 읽힌다.

알아낸 이름은 기억(`kr.stock.last`)에도 넣는다. 안 그러면 다른 화면에
갔다 돌아올 때마다 코드가 다시 뜨고 이름을 또 받아 와야 한다.

카드 제목만이 아니라 **위쪽 종목바와 차트 머리도 같이** 고쳐진다 —
이름을 `StockView` 에서 잡고 있어서 아래로 다 내려간다.

## 3. 로딩 뼈대가 안 보였다 (베낄 때 주의)

카드가 `bg-surface` 인데 로딩 자리표시도 `bg-surface` 였다. 받는 동안
**제목만 있고 아래는 완전히 텅 빈 상자**로 보인다. 데이터는 멀쩡한데
고장난 것처럼 보이는 종류의 버그다.

`bg-line/60` 처럼 한 단계 다른 색을 쓴다. 다른 카드에도 같은 실수가
없는지 한 번 볼 만하다.

## 4. 1일 수익률이 머리의 등락률과 달랐다

서로 다른 거래소를 보고 있었다. 머리의 등락률은 차트 툴바의 거래소 선택을
따라가는데, 종목상세의 기간 수익률은 네이버 일봉으로만 셌다. 일봉은 KRX
뿐이라 선택과 무관하게 늘 KRX 였다.

```
2026-08-31 셀트리온   KRX 188,900 (-0.94%)   NXT 189,300 (-0.73%)
```

NXT 나 통합을 골라 두면 머리는 -0.73%, 카드는 -0.9% 였다. 한 화면에 같은
이름의 값이 둘 떠 있으니 어느 쪽이 맞는지 알 길이 없다.

**1일은 머리와 같은 시세에서 뽑는다.** 1주 이상은 그대로 일봉이다 — NXT 는
과거 일봉이 없어 달리 셀 방법도 없다. 시세를 못 받으면 일봉으로 센 것을
그대로 둔다.

그러려면 카드가 거래소를 알아야 해서 선택을 `StockView` 로 올렸다.
`/api/stock-detail` 도 `exchange` 를 받는다.

**소수점도 맞췄다.** 머리는 `-0.94%`, 카드는 `-0.9%` 로 적어서 같은 값도
달라 보였다. 아래 일별 표와도 어긋났다. 카드도 두 자리로 쓴다. 자리는
좁지만 값이 안 맞아 보이는 대가가 더 크다.

## 5. 섹터 종합평가에서 테마를 골라도 업종이 나왔다

비교군을 거르는 검사가 `/^theme:\d+$/` 였다. 네이버 테마가 번호였을 때 쓴
것인데, 우리 분류로 갈아탄 뒤 테마 id 는 `bio-biosimilar` 같은 글자다.
검사에 걸린 값은 **조용히 `industry` 로 되돌아갔다.**

```
전  제약 · 바이오시밀러 → 둘 다 셀트리온·삼성바이오로직스·유한양행…
후  제약        S  80점  15종목 중 1위
    바이오시밀러 B+ 55점   4종목 중 1위
                          프레스티지바이오파마·삼성에피스홀딩스·이수앱지스
```

점수가 달라지는 것이 맞다 — 점수는 비교군 안에서 매긴다.

조용히 되돌리는 것이 진짜 문제였다. 화면에 아무 표시가 없어서 두 비교군이
원래 같은 것인가 싶게 만든다.

겸사겸사 업종 칩의 종목 수가 늘 0이라 안 뜨던 것도 채웠다("제약 175").

## 6. DART 분기 재무에서 4분기 자리에 연간이 들어갔다

`providers/dart.ts` 의 분기 조회가 사업보고서(11011)를 12월 분기로 섞어
넣고 있었다. 그것은 연간이다.

**코스콤으로 갈아끼우면서 재무를 DART 로 채울 자리라, 그대로 베끼면
안 되는 코드였다.**

DART 에 4분기 보고서는 없다.

| reprt_code | 보고서 | 공시 시한 |
|---|---|---|
| `11013` | 1분기보고서 | 분기말 +45일 |
| `11012` | 반기보고서 | 반기말 +45일 |
| `11014` | 3분기보고서 | 분기말 +45일 |
| `11011` | 사업보고서 | 사업연도말 +90일 |

그래서 만들어 낸다.

```
4Q = 연간(11011 thstrm_amount) − 3분기누적(11014 thstrm_add_amount)
```

분기·반기 보고서의 `thstrm_amount` 는 **그 분기 3개월치**다(누적이 아니다).
누적은 `thstrm_add_amount` 쪽에 따로 있다. 삼성전자 2025년으로 확인했다.

```
1Q 791,405   2Q 745,663   3Q 860,617      셋의 합 2,397,685
3Q 누적 2,397,686   연간 3,336,059
→ 4Q 938,373        (네이버가 내놓는 938,374 와 같다)

고치기 전에는 이 자리에 3,336,059 가 떴다 — 3.6배다.
```

**뺄셈은 흐름 항목에만 쓴다** — 매출액·영업이익·당기순이익. 부채총계·
자본총계는 잔액이라 연말 값을 그대로 쓴다. 12월 부채에서 9월 부채를 빼면
아무 뜻도 없는 수가 나온다. 3분기 누적을 못 받으면 그 칸은 비운다.

삼성전자·셀트리온 두 종목의 여섯 분기가 네이버 값과 모두 맞는 것을
확인했다.

## 7. 어느 파일이 바뀌었나

새 파일 — 그대로 넣으면 된다.

```
src/data/about.json              기업 개요 문장 1.4MB  ★ 없으면 개요가 안 뜬다
src/lib/about.ts                 그것을 읽는 층
scripts/theme/build-about.mjs    개요 문장 만들기 (분기 1회)
scripts/theme/sent.mjs           어미 다듬기 (며닫기 · 평서문)
```

고친 파일 — `바뀐자리.diff` 를 보고 반영한다. 괄호 안은 위 번호.

```
src/components/stock/StockBriefCard.tsx   개요 카드 (1) — 통째로 다시 썼다
src/app/api/stock-brief/route.ts          바깥 호출 전부 제거 (1)
src/lib/ownTheme.ts                       nameOf() · stockFixed 에 why (1·2)
src/app/stock/page.tsx                    이름 채우기 (2)
src/components/stock/StockView.tsx        이름 채우기 · 거래소 올리기 (2·4)
src/components/sections/StockSection.tsx  거래소를 위에서 받는다 (4)
src/components/stock/StockDetailCard.tsx  1일 수익률 · 소수점 두 자리 (4)
src/app/api/stock-detail/route.ts         exchange 를 받는다 (4)
src/app/api/sector-rank/route.ts          테마 비교군 검사 (5)
src/lib/naverApi.ts                       업종 종목 수 (5)
src/lib/providers/dart.ts                 4분기 계산 (6)
scripts/theme/classify.mjs                sentences · looksTable 내보내기 (1)
scripts/theme/build-data.mjs              평서문을 sent.mjs 로 옮김 (1)
```

`StockBrief.tsx` 는 **그대로 두었다.** 이름이 비슷해 헷갈리는데, 그것은
테마 화면의 종목 카드이고 거기서는 시총·매출성장·이익률·PER 을 그대로
쓴다 — 테마 화면에는 달리 볼 데가 없다.

`scripts/` 넷은 개요 문장을 분기에 한 번 새로 만들 때만 필요하다. 지금
당장은 `about.json` 만 있으면 된다.

## 무엇부터 하면 되나

**1번(기업 개요)부터.** 키가 필요 없어서 오늘 바로 붙는다 — 파일 넷
(`StockBriefCard.tsx` · `about.ts` · `about.json` · `stock-brief/route.ts`)
이면 끝난다.

**2·3번은 붙이는 김에** 같이 고치면 되는 작은 것이다. 3번(뼈대 색)은 다른
카드에도 같은 실수가 없는지 한 번 볼 만하다.

**4·5번은 값이 틀리게 보이는 것**이라 우선순위가 높다. 쓰는 사람이 먼저
알아챈 자리다.

**6번은 DART 로 재무를 채울 때** 반드시 반영해야 한다. 지금 화면에는
영향이 없지만(재무제표 카드는 네이버를 쓰고 `providers/` 는 아직 물려
있지 않다), 코스콤으로 갈아끼우는 순간 그대로 드러난다.
