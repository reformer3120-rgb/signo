# 테마 탭 — 법인 앱 × SIGNO 차이

법인 앱(signo.co.kr)에 테마 탭이 올라간 뒤 두 화면을 나란히 놓고 본 것.
2026-08-31 · IT·플랫폼 / 웹툰·웹소설 · 타이어 기준.

**데이터는 같다.** 91개 테마 · 2,497종목 · 한 종목 한 칸. 우리 것이 그대로
들어가 있다. 아래는 전부 **화면에서 어떻게 보여주나**의 차이다.

---

## 1. 목록 화면

| | 법인 앱 | SIGNO |
|---|---|---|
| 대분류 정렬 | IT·플랫폼부터 (고정?) | 등락률 순 · **정렬 바꾸기(등락/종목수/이름)** |
| 대분류 등락률 | 없음 | 대분류마다 등락률 + 막대 |
| 필터 | 없음 | **전체 / 상승 / 하락** |
| 테마 줄 | 이름 · 힌트 · 등락률 · 종목수 · 리더 3종목(등락률 포함) | 이름 · 종목수 · 리더 2종목 · 등락률 · 막대 |
| 검색 | 테마명 · 종목명 | 테마 · 종목 · **설명까지** |
| 기준일 | `2026-08-28 기준` 을 머리에 적음 | 없음 |

### 반영하면 좋을 것

**① 대분류 등락률과 막대** — 지금 법인 앱은 대분류를 펼쳐야 안이 보인다.
대분류 줄에 등락률과 막대(상승 대 하락 비율)가 있으면 접힌 채로도 어디가
움직이는지 보인다. 12개 대분류를 훑는 데 걸리는 시간이 크게 줄어든다.

**② 정렬·필터** — 91개 테마에서 오늘 오른 것만 보고 싶을 때가 많다.
`전체/상승/하락` 과 `등락/종목수/이름` 두 줄이면 된다.

**③ 검색이 설명까지 훑게** — SIGNO 는 편입 사유 문장도 검색한다.
"양극재" 로 찾으면 테마 이름에 없어도 그 낱말이 든 종목이 걸린다.

### 법인 앱이 나은 것

**기준일 표기** — `2026-08-28 기준` 이 머리에 있다. SIGNO 에는 없다.
분류가 분기에 한 번 갱신되므로 언제 자료인지 밝히는 편이 맞다.
**SIGNO 쪽에 넣어야 한다.**

**리더 종목에 등락률** — 법인 앱은 `키다리스튜디오 +4.66%` 처럼 붙어 있다.
SIGNO 는 이름만 적는다. 붙이는 편이 낫다.

---

## 2. 상세 화면 — 여기가 크게 다르다

법인 앱은 **구성종목 목록만** 나온다. SIGNO 에는 그 위에 셋이 더 있다.

```
법인 앱                        SIGNO
──────────────────            ─────────────────────────────
테마명 · 등락률 · 종목수        테마명 · 등락률
                              ① 요약 줄 — 평균 · 시총가중 · 상승/보합/하락
                              ② 한 줄 해석 — "소형주가 끌었다 …"
                              ③ 무엇을 묶었나 — 테마 정의
                              ④ 등락률 그래프 — 테마·대장주·코스피·코스닥
종목 목록                      종목 목록 (카드)
  이름 · 가격 · 등락률            이름 · 가격 · 등락률
  편입 사유 (긴 원문)             주요사업 (낱말 칩)
  매출성장 · 영업이익률            평가 (매출·이익률·PER)
                                모멘텀 (테마대비)
                              정렬 — 등락순 / 시총순 / 이름순
```

### ① 요약 줄

```
평균 +2.37%   시총 가중 +1.68%        6종목 · 상승 6 · 보합 0 · 하락 0
```

평균과 시총가중을 같이 보여주면 **소형주가 끌었는지 대형주가 끌었는지**가
바로 보인다. 테마 등락률 하나만 보면 그걸 못 가른다.

### ② 한 줄 해석

```
소형주가 끌었다 — 시총으로 가중하면 0.69%p 낮다.
```

위 두 숫자의 차이를 말로 풀어 준다. 숫자만 있으면 무슨 뜻인지 한 번 더
생각해야 한다.

### ③ 무엇을 묶었나

```
무엇을 묶었나   타이어와 그 원부자재
```

이 테마가 무엇을 모은 것인지 한 줄로 밝힌다. 목록 화면의 힌트와 같은 값이라
데이터를 새로 만들 것은 없다.

### ④ 등락률 그래프 — 없으면 아쉬운 것

```
3개월 누적 +5.39%                         [1개월] [3개월] [6개월]
  ── 테마 +5.39%
  ── 한국타이어앤테크놀로지 -7.52%   (대장주)
  ── 코스피 -21.42%
  ── 코스닥 -20.13%
```

넷을 한 판에 겹쳐 그린다. **"테마가 시장보다 나았나, 대장주 하나가 끈 건가"**
를 눈으로 가른다. 이 그래프가 없으면 테마 화면이 그냥 종목 목록이 된다.

`GET /api/themes/{no}/chart?days=90` 한 번이면 네 계열이 다 온다.

### ⑤ 종목 카드 — 편입 사유 대신 세 줄

법인 앱은 편입 사유 원문을 그대로 깐다.

```
대원미디어
당사는 현재 애니메이션 창작기획 사업, 콘텐츠 사업, 캐릭터 사업, 트레이딩
카드게임 사업, 게임 유통사업, 영화·전시이벤트 사업 및 완구 유통사업 등을
영위하고 있으며 종속회사 및 관계회사를 통해 방송 사업, 만화 출판사업 및
웹툰/웹소설 제작·유통사업을 전개하고 있다.
```

종목이 열 개 깔린 목록에서 이 문장을 읽는 사람은 없다. SIGNO 는 같은 자리에
셋을 둔다.

```
금호타이어                                        7,420  +4.36%
  주요사업   [타이어]                  시총 2.13조
  평가       매출 +3.73%  이익률 +12.25%  PER 6.1배
  모멘텀     테마대비 +2.0%p
```

**주요사업 낱말은 편입 사유 문장에서 뽑아 둔 것**이라 새 데이터가 아니다
(`themes.json` 의 `biz`). 원문은 작업지 PDF 에 남아 있으니 잃는 것도 없다.

`테마대비` 는 그 종목 등락 − 테마 등락이다. **테마 안에서 누가 끌고 누가
못 따라가는지**를 보여준다 — 테마 화면에서만 낼 수 있는 값이다.

### ⑥ 정렬

SIGNO 는 `등락순 / 시총순 / 이름순` 을 준다. 법인 앱은 등락순 고정이다.
시총순이 있으면 "이 테마의 대장주가 누구냐" 를 바로 본다.

## 3. 우선순위

값싼 것부터. 앞의 셋은 데이터가 이미 있어 화면만 고치면 된다.

```
1  종목 카드를 세 줄로        편입 사유 원문 → 주요사업·평가·모멘텀   (1~2일)
                             themes.json 의 biz·growth·opm·per 사용
2  요약 줄 + 한 줄 해석       평균·시총가중·상승/하락 개수            (반나절)
3  무엇을 묶었나              목록 화면의 힌트와 같은 값               (반나절)
4  대분류 등락률·막대 + 정렬·필터                                   (1~2일)
5  등락률 그래프              /api/themes/{no}/chart 한 번           (2~3일)
6  기준일 표기               ← 이건 SIGNO 쪽에 넣어야 한다
```

**1번이 가장 크다.** 지금은 목록에서 아무도 안 읽는 문장이 화면의 대부분을
차지한다. 세 줄로 끊으면 눈이 필요한 줄로 바로 간다.

**5번이 가장 아쉽다.** 그래프가 없으면 테마 화면이 종목 목록과 다를 게 없다.
다만 시세 시계열이 필요해 앞의 넷보다 손이 간다.

---

## 4. SIGNO 쪽에 반영할 것

법인 앱을 보고 우리가 빠뜨린 것을 찾았다.

- **기준일 표기** — `2026-08-28 기준` 을 목록 머리에 적는다. 분류는 분기에
  한 번 바뀌므로 언제 자료인지 밝혀야 한다.
- **리더 종목에 등락률** — 지금은 이름만 적는다. `키다리스튜디오 +4.66%`
  처럼 붙이면 접힌 채로도 정보가 는다.
