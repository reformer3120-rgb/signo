# 테마 탭 — 법인 앱 × SIGNO 세밀 대조

2026-08-31 · 두 화면의 텍스트를 통째로 뽑아 대조했다.
법인 앱 signo.co.kr `/market/themes` · SIGNO `/theme`

**데이터는 같다.** 91개 테마 · 2,497종목 · 한 종목 한 칸. 우리 것이 그대로
들어가 있다. 아래는 전부 **화면에서 어떻게 보여주나**의 차이다.

---

## 1. 목록 화면

### 1.1 머리

```
법인 앱   테마
          91개 테마 · 2,497종목 · 2026-08-28 기준
          사업보고서를 읽어 만든 분류예요. 한 종목은 한 테마에만 들어갑니다.

SIGNO     테마 91                    [전체][상승][하락]  [등락][종목수][이름]
          (검색창)
          … 목록 …
          테마 분류와 편입 사유는 SIGNO 가 DART 사업보고서로 직접 만든 것이다.
          등락률은 편입 종목의 단순 평균이고, 막대는 상승 대 하락 비율이다.
```

| | 법인 앱 | SIGNO |
|---|---|---|
| 종목수 표기 | `2,497종목` 있음 | 없음 |
| **기준일** | **`2026-08-28 기준` 있음** | **없음** |
| 설명 위치 | 머리에 — 먼저 읽힌다 | 맨 아래 각주 |
| 설명 말투 | "…들어갑니다" (경어) | "…만든 것이다" (평서) |
| 필터·정렬 | 없음 | 머리에 두 줄 |

**기준일은 법인 앱이 맞다.** 분류가 분기에 한 번 갱신되므로 언제 자료인지
밝혀야 한다. SIGNO 에 넣어야 할 것.

**설명을 머리에 두는 것도 법인 앱이 낫다.** "한 종목은 한 테마에만"은 이
화면을 처음 보는 사람이 가장 먼저 알아야 하는 규칙인데, SIGNO 는 맨 아래
각주에 있어 아무도 안 읽는다.

### 1.2 대분류 줄

```
법인 앱   IT·플랫폼   14개
          (바로 아래에 14개 테마가 전부 펼쳐져 있다)

SIGNO     ▶ 소비재    테마 14 · 324종목    ▬▬▬▬▬  +1.61%
          ▶ 자동차    테마 3 · 85종목      ▬▬▬▬▬  +1.58%
          … 12줄 …
```

| | 법인 앱 | SIGNO |
|---|---|---|
| 접기/펼치기 | 없음 — 전부 펼쳐진 긴 스크롤 | 아코디언, 눌러서 편다 |
| 종목수 | 없음 (테마 개수만) | `테마 14 · 324종목` |
| **등락률** | **없음** | 있음 |
| **막대** | **없음** | 상승 대 하락 비율 |
| 정렬 | 고정으로 보인다 (IT·플랫폼이 먼저) | 등락률 내림차순 |

**대분류 등락률과 막대가 없는 것이 가장 큰 차이다.** 법인 앱은 12개 대분류
중 어디가 움직이는지 알려면 91개 테마를 다 스크롤해야 한다. SIGNO 는 12줄만
보면 끝난다.

접힌 상태의 값어치가 여기 있다 — **91개를 훑기 전에 12개로 좁힌다.**

### 1.3 테마 줄

```
법인 앱   웹툰·웹소설
          웹툰·웹소설 플랫폼 또는 제작(CP)          ← 설명이 있다
          +4.21%   10종목
          키다리스튜디오 +4.66%  고스트스튜디오 +13.10%  디앤씨미디어 +1.54%

SIGNO     타이어   6   금호타이어, HS효성첨단소재   ▬▬▬  +2.37%
```

| | 법인 앱 | SIGNO |
|---|---|---|
| **테마 설명** | **있다** — 한 줄로 무엇을 묶었는지 | **없다** (상세에만) |
| 리더 종목 | **3개 · 등락률 포함** | 2개 · 이름만 |
| 등락률 | 있음 | 있음 |
| 막대 | 없음 | 있음 |
| 종목수 | `10종목` | `6` |
| 한 줄 높이 | 4줄 | 1줄 |

**설명과 리더 등락률은 법인 앱이 낫다.** "웹툰·웹소설 플랫폼 또는 제작(CP)"
한 줄이 있으면 테마 이름만으로 애매한 것들이 풀린다. 리더에 등락률이 붙으면
"테마는 +4.21%인데 고스트스튜디오 혼자 +13.10%로 끌었나" 가 바로 보인다.

**대신 한 줄이 4줄이 되어 화면에 5~6개밖에 안 들어간다.** SIGNO 는 1줄이라
접었다 폈다 하며 훑기 좋다. 둘 다 취하려면 설명을 작게 한 줄 더 붙이는
정도가 맞다.

### 1.4 검색

```
법인 앱   "테마나 종목 이름으로 찾기"
SIGNO     "테마·종목·설명 — 예: HBM, 양극재, 삼성SDI"
```

SIGNO 는 **편입 사유 문장까지 훑는다.** "양극재" 로 찾으면 테마 이름에 없어도
그 낱말이 든 종목이 걸린다. 법인 앱은 이름만 찾는다.

## 2. 상세 화면 — 여기가 크게 다르다

### 2.1 머리

```
법인 앱   IT·플랫폼                                   +4.21%    ✕
          웹툰·웹소설                                 10종목 · 7/2
          웹툰·웹소설 플랫폼 또는 제작(CP)

SIGNO     ← 테마   타이어  +2.37%          [등락순][시총순][이름순]

          평균 +2.37%    시총 가중 +1.68%     6종목 · 상승 6 · 보합 0 · 하락 0
          ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬
          소형주가 끌었다 — 시총으로 가중하면 0.69%p 낮다.

          무엇을 묶었나  타이어와 그 원부자재

          3개월 누적 +5.39%                    [1개월][3개월][6개월]
            ── 테마 +5.39%
            ── 한국타이어앤테크놀로지 -7.52%
            ── 코스피 -21.42%
            ── 코스닥 -20.13%          6/4 ~ 8/28
```

법인 앱은 **모달**로 뜨고(✕ 로 닫는다), SIGNO 는 **화면 전환**이다(← 테마).

법인 앱에 없는 것 넷:

**① 시총 가중 등락률** — `평균 +2.37% / 시총 가중 +1.68%`
둘을 같이 보여주면 소형주가 끌었는지 대형주가 끌었는지 갈린다.
법인 앱은 `+4.21%` 하나뿐이라 그걸 못 가른다.

**② 한 줄 해석** — `소형주가 끌었다 — 시총으로 가중하면 0.69%p 낮다.`
위 두 숫자의 차이를 말로 푼다. 숫자만 있으면 한 번 더 생각해야 한다.

**③ 무엇을 묶었나** — `타이어와 그 원부자재`
법인 앱도 머리에 힌트를 적으므로 사실상 같다. 다만 SIGNO 는 별도 블록으로
띄워 둔다.

**④ 등락률 그래프** — 넷을 한 판에 겹친다.
```
테마 +5.39%   대장주 -7.52%   코스피 -21.42%   코스닥 -20.13%
```
**"테마가 시장보다 나았나, 대장주 하나가 끈 건가"** 를 눈으로 가른다.
여기서는 대장주가 -7.52% 인데 테마가 +5.39% 다 — 대장주 빼고 나머지가
끌었다는 뜻이고, 이건 그래프 없이는 안 보인다.

법인 앱의 `10종목 · 7/2` 는 상승 7 · 하락 2 로 보인다. SIGNO 는
`6종목 · 상승 6 · 보합 0 · 하락 0` 으로 풀어 쓴다.

### 2.2 종목 카드 — 가장 큰 차이

```
법인 앱
  대원미디어                                              5,900  +3.69%
  당사는 현재 애니메이션 창작기획 사업, 콘텐츠 사업, 캐릭터 사업, 트레이딩
  카드게임 사업, 게임 유통사업, 영화·전시이벤트 사업 및 완구 유통사업 등을
  영위하고 있으며 종속회사 및 관계회사를 통해 방송 사업, 만화 출판사업 및
  웹툰/웹소설 제작·유통사업을 전개하고 있다.
  매출성장 33.7%   영업이익률 2.9%   2025 기준

SIGNO
  금호타이어                                              7,420  +4.36%
  주요사업   [타이어]                       시총 2.13조
  평가       매출 +3.73%  이익률 +12.25%  PER 6.1배
  모멘텀     테마대비 +2.0%p
```

| | 법인 앱 | SIGNO |
|---|---|---|
| 사업 설명 | 편입 사유 **원문** (2~5줄) | **낱말 칩** (1~3개) |
| 시가총액 | 없음 | 있음 |
| PER | 없음 | 있음 |
| 매출성장·이익률 | 있음 (`2025 기준` 표기) | 있음 (기준연도 표기 없음) |
| **테마대비** | **없음** | 있음 |
| 정렬 | 등락순 고정 | 등락순 / 시총순 / 이름순 |

**원문을 그대로 까는 것이 문제다.** 종목이 열 개 깔린 목록에서 다섯 줄짜리
문장을 읽는 사람은 없다. 게다가 대원미디어의 저 문장은 웹툰 이야기가 맨
뒤에 나온다 — 왜 이 테마에 있는지가 오히려 안 보인다.

**낱말 칩은 그 원문에서 뽑아 둔 것**이라 새 데이터가 아니다(`themes.json`
의 `biz`). 원문은 작업지 PDF 에 남아 있으니 잃는 것도 없다.

**테마대비**(그 종목 등락 − 테마 등락)는 테마 화면에서만 낼 수 있는 값이다.
`+2.0%p` 면 테마를 끌고 있다는 뜻이고 `-1.8%p` 면 못 따라간다는 뜻이다.
법인 앱에는 없다.

**기준연도 표기는 법인 앱이 낫다.** `2025 기준` 이 붙어 있다. SIGNO 는
카드에 없고 각주에만 "DART 확정 실적" 이라고 적는다.

### 2.3 각주

```
법인 앱   (없음)

SIGNO     편입 사유는 그 종목의 사업보고서에서 뽑은 문장이다. 테마 분류도
          SIGNO 가 직접 만든 것이다. 매출성장·영업이익률은 DART 확정 실적,
          시가총액·PER 은 한국투자증권 시세 기준.
```

출처를 밝히는 줄이 법인 앱에는 없다. 어디서 온 숫자인지 밝히는 편이 맞다.

## 3. 법인 앱에 반영할 것 — 우선순위

앞의 셋은 데이터가 이미 있어 화면만 고치면 된다.

```
1  종목 카드를 세 줄로       원문 → 주요사업(칩) · 평가 · 모멘텀      1~2일
                            themes.json 의 biz · growth · opm · per
                            + 테마대비 (종목 등락 − 테마 등락)

2  요약 줄 + 한 줄 해석      평균 · 시총가중 · 상승/보합/하락 개수     반나절
                            "소형주가 끌었다 — …" 문장까지

3  구성종목 정렬            등락순 / 시총순 / 이름순                 반나절

4  대분류에 등락률·막대      12줄만 보고 어디가 움직이는지 알게       1~2일
   + 목록 필터·정렬         전체/상승/하락 · 등락/종목수/이름

5  검색이 설명까지 훑게      "양극재" 로 종목이 걸리게                반나절

6  등락률 그래프            테마·대장주·코스피·코스닥 넷을 겹쳐       2~3일
                            /api/themes/{no}/chart?days=90 한 번
```

**1번이 가장 크다.** 지금은 아무도 안 읽는 문장이 화면의 대부분을 차지한다.

**6번이 가장 아쉽다.** 그래프가 없으면 테마 화면이 종목 목록과 다를 게 없다.
다만 시세 시계열이 필요해 앞의 다섯보다 손이 간다.

## 4. SIGNO 에 반영할 것

법인 앱을 보고 우리가 빠뜨린 것을 찾았다. 셋 다 작다.

```
1  기준일 표기          "2026-08-28 기준" 을 목록 머리에
                        분류는 분기에 한 번 바뀐다 — 언제 자료인지 밝혀야 한다

2  설명을 머리로         "한 종목은 한 테마에만 들어갑니다" 가 지금은
                        맨 아래 각주에 있어 아무도 안 읽는다

3  목록에 테마 설명       테마 줄에 힌트 한 줄 (작게)
                        + 리더 종목에 등락률 붙이기
                        단, 한 줄이 여러 줄이 되지 않게 — 훑기 쉬운 것이
                        SIGNO 목록의 장점이다
```
