# 종목 화면 구현 명세 — 법인 앱

목표 화면(2026-08-31 목업)을 그대로 만들기 위한 명세다. 위에서 아래로
블록 순서대로 적었고, 각 블록마다 **무엇을 그리나 · 어디서 받나 · 다 됐다고
볼 조건**을 붙였다.

기준 API 는 SIGNO(`signo-chi.vercel.app`) 것이고, 응답은 2026-08-31
셀트리온(068270)에서 실제로 받은 값이다. 코스콤으로 갈아끼우는 방법은
`README.md`(PORTING-STOCK-TAB), 두 앱을 어떻게 나눌지는 `합치기-명세.md`.

---

## 0. 전체 순서

```
헤더            종목명 · 코드 · 현재가 · 테마칩 · ★
탭              차트 / 정보 / 뉴스 / AI
────────────── 아래는 '차트' 탭 ──────────────
차트            봉주기 · 지표 · 드로잉 · 지지저항
종목 개요       주요사업 · 평가 · 모멘텀          ← SIGNO
종목 상세       수급 · 기간수익률 · 지표 12칸      ← SIGNO
재무제표        연간/분기 · 컨센서스               ← SIGNO
유동물량        상장·유통 주식수 · 유통비율        ← 법인 (이미 있음)
대주주 현황     상위 5                            ← 법인 (이미 있음)
성장점수        매출·영업·순이익 + CAGR            ← 법인 (이미 있음)
```

**정해야 할 것 하나** — 이 순서대로면 차트 탭 하나에 다 들어간다. 지금
법인 앱은 유동물량·대주주가 '정보' 탭에 있는데, 목업은 한 줄로 이어져 있다.
둘 중 하나를 고른다.

```
A. 목업대로 — 차트 탭에 다 쌓는다. 정보 탭은 투자자 매매동향·수급추이만 남는다
B. 나눈다   — 개요·상세는 차트 탭, 재무제표·유동물량·대주주는 정보 탭
```

아래 명세는 **A 기준**으로 적었다. B 로 갈 거면 블록 위치만 옮기면 되고
데이터 계약은 같다.

## 1. 헤더

```
셀트리온  [코스피]  068270 ▾                              ★
190,400  ↘ -0.47% (-900원)      바이오시밀러 -0.05%
```

- 종목명 옆 `▾` 를 누르면 종목 검색이 열린다
- `★` 는 관심종목 담기 (기존 동작 그대로)
- **점수 배지는 넣지 않는다.** 목업에는 원형 `98` 이 있었으나 빼기로 했다.
  성장점수(98)와 종합평가(66)가 한 화면에 나란히 뜨면 어느 쪽을 봐야 하는지
  알 수 없다. 두 점수는 각자 제자리에서 이름을 달고 뜬다.

### 테마 칩

```
바이오시밀러 -0.05%
```

`GET /api/stock-themes?code=068270` → SIGNO 테마 분류.
지금 정보 탭의 "테마" 자리에는 표준산업분류(`기초 의약물질 및 생물학적 제제
제조업`)가 들어가 있다. 그것을 이 값으로 바꾼다.

숫자는 그 테마 구성종목의 오늘 등락률 평균이다. 칩을 누르면 같은 테마
종목 목록으로 간다.

**데이터는 `src/data/themes.json` 한 파일에 다 있다.** 시세도 키도 필요 없다.
자세한 것은 `테마탭-인계.md`.

> 됐다고 볼 조건 — 셀트리온에서 `바이오시밀러`, 삼성바이오로직스에서
> `바이오 CDMO` 가 뜬다. 표준산업분류 문구가 화면 어디에도 남아 있지 않다.

기존 구현을 그대로 쓴다. 목업과 다른 점만 적는다.

```
봉주기   5분 15분 30분 1시간 4시간 일 주 월        (그대로)
지표     SMA(1)▾  BB  RSI  MACD | 패턴(12) | 추세선  FVG  OB   (그대로)
드로잉   추세선 연장선 수평선 수직선 박스 텍스트 측정 복사 지우기  (그대로)
지지저항 저항2 211,326 · 저항1 193,969 · 지지1 184,143 …        (그대로)
```

## 3. 종목 개요 — 세 칸  ← 새로 붙임

```
셀트리온 개요
  주요사업  항체 바이오시밀러   특허 만료된 바이오의약품의 복제약
            바이오시밀러 5종목   시총 44.36조
  평가      SIGNO 66점 · 매출25년 +17.01% · 이익률 +28.07% · PER 29.0배
            증권가목표 274,621원 +43.60% · 의견 4.0/5
  모멘텀    1개월 +0.37% · 골든크로스 · 외국인 25.6%
```

### 받는 곳

`GET /api/stock-brief?code=068270`

```json
{
  "biz": ["항체 바이오시밀러", "특허 만료된 바이오의약품의 복제약"],
  "themeName": "바이오시밀러",
  "themeCount": 5,
  "themeChg": -0.05,
  "cap": 443601,
  "score": 66,
  "growth": 17.01,
  "opm": 28.07,
  "finYear": 2025,
  "per": 29.03,
  "target": 274621,
  "upside": 43.6,
  "recomm": 4,
  "ret1m": 0.37,
  "cross": "골든크로스",
  "foreign": 25.55
}
```

| 화면 | 필드 | 비고 |
|---|---|---|
| 주요사업 낱말 | `biz[]` | 편입 사유 문장에서 품목만 뽑아 둔 것 |
| 테마 N종목 | `themeName` `themeCount` | |
| 시총 | `cap` | 억원 |
| SIGNO 점수 | `score` | 없으면 그 조각만 지운다 |
| 매출YY | `growth` `finYear` | |
| 이익률 | `opm` | |
| PER | `per` | |
| 증권가목표 | `target` `upside` | 컨센서스 — 무료 출처가 없다 |
| 의견 | `recomm` | 5점 만점 |
| 1개월 | `ret1m` | |
| 이평선 | `cross` | 정배열·역배열·혼조·골든크로스·데드크로스 |
| 외국인 | `foreign` | % |

### 규칙 두 가지

**빈 칸은 "—" 로 채우지 말고 줄째로 지운다.** 자료가 종목마다 다르다.
컨센서스는 시총 상위 2할에만 있고, 점수는 지표 크론이 훑은 종목에만 있다.
빈 칸이 늘어선 화면은 고장난 것처럼 보인다.

**`cross` 는 그대로 적는다.** 확인되지 않은 교차는 API 가 아예 크로스로
내보내지 않고 `혼조` 로 준다. 화면에서 `?` 를 붙이거나 색을 죽일 필요가 없다.

> 됐다고 볼 조건 — 셀트리온에서 세 줄이 다 차고, 컨센서스가 없는 중소형주
> (예: 대양금속)에서는 `증권가목표`·`의견` 조각만 빠진 채 나머지가 정상으로
> 보인다. "—" 가 화면에 남지 않는다.

## 5. 재무제표  ← 새로 붙임

```
재무제표                                      [연간] 분기     억원 · E=추정

2026.12 가이던스   애널리스트 컨센서스 추정 · 2025.12 대비
 매출액 55,304 +32.9%   영업이익 18,550 +58.8%   당기순이익 15,911 +54.3%
 영업이익률 33.54% +5.47%p   ROE 8.83% +2.89%p   EPS 6,725 +58.7%

항목        2023.12.   2024.12.   2025.12.   2026.12.E
매출액        21,764     35,573     41,625     55,304
영업이익       6,515      4,920     11,685     18,550
당기순이익      5,397      4,189     10,315     15,911
영업이익률     29.93%     13.83%     28.07%     33.54%
순이익률      24.80%     11.77%     24.78%     28.77%
ROE           5.07%      2.46%      5.94%      8.83%
부채비율       16.53      19.77      28.71          -
EPS           3,187      1,703      4,238      6,725
```

### 받는 곳

`GET /api/financials?code=068270`

```json
{
  "periods": [
    { "title": "2023.12.", "cns": false },
    { "title": "2026.12.", "cns": true }
  ],
  "rows": [
    { "title": "매출액", "values": ["21,764", "35,573", "41,625", "55,304"] }
  ]
}
```

`cns: true` 인 열이 컨센서스(추정)다. 머리글에 `E` 를 붙이고 색을 달리해
실적과 구분한다. 구분하지 않으면 추정치를 실적으로 읽는다.

위쪽 가이던스 카드는 마지막 열(추정)과 그 앞 열(실적)의 차이로 만든다.
`%p` 는 비율 항목(영업이익률·ROE)에만 쓴다.

`-` 는 그 기간에 값이 없다는 뜻이므로 0 으로 바꾸지 않는다.

> 됐다고 볼 조건 — 연간/분기 토글이 돌고, 추정 열이 눈으로 구분되며,
> 부채비율 2026.12.E 자리가 `-` 로 남아 있다.

## 7. 붙이는 순서

앞이 될수록 값싸고 눈에 띄는 변화가 크다.

```
1  테마 칩 교체        themes.json 만 있으면 된다. 키·시세 불필요       (반나절)
2  52주 최고/최저      stock-detail 에 들어 있다. 빈 줄부터 없앤다       (반나절)
3  종목 개요 세 칸      stock-brief 한 번 부르면 된다                   (1~2일)
4  종목 상세 12칸       stock-detail 한 번                              (1~2일)
5  재무제표            financials 한 번 + 가이던스 카드 계산            (2~3일)
```

1·2 는 데이터가 이미 있어 바로 된다. 3~5 는 코스콤이 못 주는 항목
(재무·컨센서스)이 섞여 있으므로 DART 키가 필요하다 — `README.md` §4.

업종 내 순위(SectorRankCard)는 이 목업에 없어서 뺐다. 넣을 거면 비교군
전체의 재무가 필요해 DART 하루 2만 건 제한에 걸린다. 크론으로 미리 쌓는
구조가 따로 있어야 한다(`README.md` §7).
