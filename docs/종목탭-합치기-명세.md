2026-08-31 · 법인 앱 실물(셀트리온 068270)을 보고 적었다.

이식 자체(코스콤으로 데이터 갈아끼우기)는 `PORTING-STOCK-TAB.md` 를 볼 것.
이 문서는 **두 화면을 어떻게 합칠 것인가**만 다룬다.

## 2. 정한 것

### 2.1 헤더 배지에 점수를 넣지 않는다

목업에는 헤더에 원형 `98`, 개요에 `SIGNO 66점` 이 같이 있었다. 성격이 다른
두 점수가 한 화면에 나란히 뜨면 어느 쪽을 봐야 하는지 알 수 없다.

```
성장점수 98   매출 성장 추세만 본다
종합평가 66   재무·밸류·성장·수급·시총·주가흐름·배당 일곱 가지
```

**헤더는 종목명·코드·현재가·등락률·관심종목(★) 까지만 둔다.** 점수는 각자
제자리(성장점수는 재무 신호등, 종합평가는 개요 카드)에서 이름을 달고 뜬다.

### 2.2 테마는 SIGNO 분류로 바꾼다

지금 정보 탭의 "테마" 자리에 **표준산업분류**가 들어가 있다.

```
지금   테마   기초 의약물질 및 생물학적 제제 제조업
후     테마   바이오시밀러 · 같은 테마 5종목 · 눌러서 이동
```

`src/data/themes.json` 하나면 된다. 시세도 키도 필요 없다.
자세한 것은 `docs/테마탭-인계.md`.

## 3. 어디에 무엇을 넣나

법인 앱 종목 상세는 탭이 넷이다 — 차트 / 정보 / 뉴스 / AI.

```
차트 탭
  (지금 그대로)
  + 종목 개요 세 칸        차트 아래, 성장점수 위
                          주요사업 · 평가 · 모멘텀

정보 탭
  기업 정보                테마 줄을 SIGNO 분류로 교체 (§2.2)
                          52주 최고/최저 채우기 (§4.1)
  유통물량                 (그대로)
  대주주 현황              (그대로)
  투자자별 매매동향         (그대로)
  수급 추이 30일           (그대로)
  + 업종 내 순위           SIGNO 의 SectorRankCard
  + 재무제표               연간/분기 · 컨센서스 열
```

**개요 세 칸을 차트 탭에 두는 이유** — 종목에 들어오면 가장 먼저 보이는
자리다. "이 회사가 무엇으로 버는가"를 모르고 차트를 보는 것은 순서가 뒤집힌
것이다. 정보 탭까지 들어가야 알 수 있으면 아무도 안 본다.

개요 세 칸의 내용과 출처는 `PORTING-STOCK-TAB.md` §3 에 표로 있다.

## 4. 법인 앱에서 눈에 걸린 것

실물을 보다 발견한 것이라 같이 적어 둔다.

### 4.1 52주 최고 · 최저가 비어 있다

```
52주 최고    -
52주 최저    -
```

SIGNO 에는 258,500 / 145,200 이 나온다. 일봉만 있으면 계산되는 값이라
따로 받을 필요가 없다. 화면에 "-" 가 두 줄 붙어 있으면 고장난 것처럼 보인다.

### 4.2 분봉이 어디서 오는지 확인해야 한다

`PORTING-STOCK-TAB.md` 에 "코스콤은 분봉을 주지 않는다" 고 적어 두었는데,
법인 앱은 5·15·30분·1시간·4시간이 모두 돌아간다(8/28 11:00~15:25 확인).

셋 중 하나다. **어느 쪽인지 확인해서 이식 문서를 고쳐야 한다.**

```
1. 코스콤 계약에 분봉이 포함돼 있다        → 문서가 틀렸다. 고친다
2. 실시간 시세를 받아 집계해 쌓고 있다      → 그 구조를 이식 문서에 적는다
3. 다른 출처를 쓴다                       → 라이선스를 확인해야 한다
```

## 5. 겹치는 것을 어떻게 할까

한쪽을 지워야 하는 것은 아니지만, 같은 값이 두 번 나오면 정리하는 편이 낫다.

| 항목 | 법인 앱 | SIGNO | 제안 |
|---|---|---|---|
| 시가총액·PER·PBR·EPS·배당 | 정보 탭 기업정보 | 종목 상세 카드 | 정보 탭 쪽만 남긴다 |
| 재무 요약 | 성장점수 신호등 | 재무제표 카드 | 둘 다 둔다 — 보는 깊이가 다르다 |
| 점수 | 성장점수 | 종합평가 | 둘 다 두되 헤더에는 안 올린다 (§2.1) |

## 6. 붙이는 순서

```
1  테마 줄 교체        themes.json 만 있으면 된다. 키·시세 불필요
2  52주 최고/최저      일봉에서 계산. 빈 줄부터 없앤다
3  종목 개요 세 칸      차트 탭 아래. 코스콤+DART 로 채워진다
4  업종 내 순위        DART 재무가 비교군 전체에 필요 — 크론으로 미리 쌓는다
5  재무제표            컨센서스 열은 무료 출처가 없다. 빼는 편이 낫다
```

1·2 는 데이터가 이미 있어 바로 된다. 3 부터는 DART 키가 필요하다.
4 는 비교군 전체를 매번 조회하면 DART 하루 2만 건 제한에 걸리므로,
SIGNO 의 `/api/cron/metrics` 처럼 미리 쌓아 두는 구조가 필요하다.
