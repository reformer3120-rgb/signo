# 기업개요·매출구성 — 법인팀 전달 자료

파일 둘입니다. `기업개요.csv` · `매출구성.csv`

둘 다 DART 사업보고서 원문에서 읽은 것입니다. 지어낸 문장도, 손으로 옮겨 적은
숫자도 없습니다(예외 한 가지는 아래 「손보기」 에 적어 두었습니다).

## 기업개요.csv

```
종목코드,종목명,문장수,개요1,개요2,개요3,개요4
005930,삼성전자,3,메모리반도체·스마트폰·TV·가전을 아우르는 …,본사를 거점으로 …,사업별로 보면 …,
```

2,417종목 · 6,554문장 · 종목당 평균 2.71문장.

- **개요1** 은 대개 저희가 테마 분류에 쓰는 한 줄입니다. 사람이 손본 것이라
  가장 짧고 분명합니다.
- **개요2 이후**는 사업보고서 「II. 사업의 내용 — 사업의 개요」 원문에서 고른
  문장입니다. **원문 순서를 지킵니다.** 점수순으로 늘어놓으면 「무슨 회사다 →
  무엇을 만든다 → 어디에 판다」 흐름이 깨져 읽기 나빠집니다.
- 문체는 「-다」 로 맞췄습니다. 뜻은 건드리지 않았습니다.
- 산업 전망·시황·실적 숫자가 든 문장은 뺐습니다. 개요는 「이 회사가 무슨 일을
  하는가」 만 담습니다.

빠진 종목이 80 있습니다. 사업보고서가 아직 없는 신규 상장, 펀드·리츠, 그리고
원문이 표뿐이라 문장을 한 톨도 못 건진 회사입니다.

## 매출구성.csv

```
종목코드,종목명,구분,조각,비중,기준보고서,기준일
005930,삼성전자,매출 구성,DS 부문,62.9,반기보고서 (2026.06),2026-08-14
```

2,091종목 · 6,156줄. 한 종목이 조각 수만큼 줄을 차지합니다.

- **비중** 은 %, 소수점 첫째 자리. 그 종목의 조각 합이 100이 되도록 저희가
  다시 계산한 값입니다. 원문에 적힌 비율을 그대로 옮기지 않았습니다 — 회사마다
  분모가 다릅니다.
- **기준보고서·기준일** 은 그 표가 실린 공시입니다. 반기보고서 1,810 ·
  사업보고서 253 · 분기보고서 28.

### 「구분」 칸을 꼭 보십시오

같은 파일에 성격이 다른 셋이 섞여 있습니다.

| 구분 | 종목 수 | 뜻 |
|---|---|---|
| 매출 구성 | 2,012 | 조각의 합이 그 해 매출액과 맞습니다. 매출 비중이라 불러도 됩니다 |
| 사업 구성 | 77 | 사업부문이 무엇무엇인지는 맞지만, 그 비율이 매출 비중인지는 **장담하지 않습니다** |
| 영업이익 구성 · 순이자손익 구성 | 2 | **매출이 아닙니다.** 신한지주·기업은행입니다 |

「사업 구성」 은 회사 매출액을 구할 길이 없어 못 견준 것입니다. 코넥스·비상장·
상장폐지 종목이 대부분입니다.

금융지주는 부문별 매출을 아예 공시하지 않습니다. 그래서 신한지주는 부문별
영업이익, 기업은행은 부문별 순이자손익으로 실었습니다. **이 둘을 매출 비중으로
읽으면 틀립니다.** 화면에서도 「영업이익 구성」 이라 따로 적습니다.

### 조각 이름은 회사가 적은 그대로입니다

표에 적힌 부문명을 그대로 옮깁니다. 「DX 부문」 「HS」 「RV」 처럼 회사마다 말이
다릅니다. 저희가 통일하지 않았습니다 — 통일하려면 회사별 판단이 들어가고,
그러면 원문과 어긋납니다.

각주 표시(주1)와 「-」 같은 빈 칸은 뗐고, 각주를 떼어 이름이 겹치면 합쳤습니다.

## 못 담은 것

- **삼성생명·삼성화재** — IFRS17 아래서 부문별 수익을 아예 안 냅니다. 계약집합별
  보험계약마진만 있습니다. 시총 상위 50 중 이 둘만 빠져 있습니다.
- **단일사업 회사** — 부문이 하나뿐이면 조각도 하나입니다. 조각이 하나인 종목은
  합이 매출액과 맞을 때만 실었습니다(「반도체 장비재료 100%」).
- **펀드·리츠** — 맥쿼리인프라 등. 사업보고서 자체가 없습니다.

## 손보기

종목별로 잣대가 안 맞는 것은 `scripts/theme/매출표-손보기.json` 에 적어
두었습니다. 지금 다섯 종목입니다(기아·미래에셋증권·신한지주·기업은행·
두산에너빌리티). **값을 적어 둔 것이 아니라 어느 칸·어느 줄을 읽을지만**
적어 둔 것이라, 다음 분기 보고서가 나와도 숫자는 새로 읽힙니다.

## 다시 뽑으려면

```bash
node scripts/theme/collect.mjs --다시          # 개요 원문        (10분)
node scripts/theme/build-about.mjs --write     # → src/data/about.json
node scripts/theme/build-about.mjs --csv       # → 기업개요.csv

node scripts/theme/collect-segments.mjs --묵은것  # 매출 표
node scripts/theme/build-profile.mjs           # → src/data/profile.json
node scripts/theme/build-profile.mjs --csv     # → 매출구성.csv
```

원문은 `.cache/dart/` 에 남겨 두므로 다시 돌려도 DART 를 거의 두드리지
않습니다. 규칙만 고쳐 다시 뽑을 때는 호출이 한 자릿수입니다.

인코딩은 UTF-8, 줄바꿈은 LF, 종목명 가나다순입니다.
