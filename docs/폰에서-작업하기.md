# 폰에서 작업하기

집 PC 를 켜 두지 않아도 웬만한 일은 된다. **무엇이 되고 무엇이 안 되는지**를
먼저 갈라 두면 헤매지 않는다.

---

## 1. 폰만으로 되는 것 (PC 꺼져 있어도 된다)

claude.ai/code 를 폰 브라우저로 열고 `reformer3120-rgb/signo` 저장소를 고른다.
클라우드에서 돌기 때문에 이 PC 와 아무 상관이 없다.

```
화면·UI 고치기            카드 배치, 색, 글자, 반응형
로직 고치기               점수 산식, 정렬, 필터, 라우트
버그 잡기                 재현 → 원인 → 수정 → 배포
문서 쓰기                 인계 문서, 명세
법인 꾸러미 다시 묶기      node scripts/pack-stock-delta.mjs
```

고치고 `main` 에 push 하면 Vercel 이 자동 배포한다. 폰 브라우저로
https://signo-chi.vercel.app 를 열어 눈으로 확인하면 한 바퀴가 닫힌다.

### 확인은 배포본으로 한다

클라우드 세션에는 키가 없어서 로컬 개발 서버(`npm run dev`)를 띄워도 시세가
안 나온다. 그럴 필요도 없다 — **배포본에는 키가 다 들어 있다.** Vercel 환경
변수에 넣어 두었기 때문이다.

```
https://signo-chi.vercel.app/api/quote?code=005930
https://signo-chi.vercel.app/api/stock-brief?code=068270
https://signo-chi.vercel.app/api/sector-rank?code=068270&group=theme:bio-biosimilar
```

2026-09-07 에 여섯 개를 찔러 확인했다. 전부 200 이다.

## 2. 이 PC 가 있어야 하는 것

```
개요 문장 새로 만들기       .cache/theme/overview.json (17.8MB) 이 필요
테마 분류 다시 돌리기       .cache/theme/ 39MB 이 필요
DART 로 무언가 새로 수집    DART_API_KEY 가 필요
윗층 테마판 주간 갱신       이미 자동이다 (아래)
```

**왜 클라우드에서 안 되나** — 사업보고서 원문 39MB 는 저장소에 없다. 배포에
실을 것이 아니고, 만든 결과(`src/data/themes.json` · `about.json` ·
`upper.json`)만 커밋한다. 그 결과 파일들은 저장소에 있으므로 **화면 작업에는
지장이 없다.** 원문이 필요한 것은 문장을 *다시 만들* 때뿐이고, 그것은 분기에
한 번이다.

### 윗층 테마판은 이미 자동이다

이 PC 의 작업 스케줄러가 **매주 월요일 07:00** 에 돌려서 커밋·푸시까지 한다.
PC 가 꺼져 있었으면 켜진 뒤 따라 돈다. 폰에서 할 일이 없다.

```
확인   schtasks /query /tn "SIGNO-upper-refresh" /v /fo list
로그   C:\signo\.cache\refresh-upper.log
```

## 3. 그래도 PC 를 직접 만져야 할 때

분기 작업(개요 문장·테마 분류)을 밖에서 돌려야 하는 경우다. 셋 중 하나를
깔면 되는데, 아직 아무것도 깔지 않았다.

| | 폰에서 | 설치 | 쓸 만한가 |
|---|---|---|---|
| Chrome 원격 데스크톱 | 브라우저 | PC 에 확장 + 호스트 | 화면을 통째로 본다. 폰 화면이 좁아 타이핑은 불편 |
| Tailscale + SSH | 터미널 앱 | 양쪽에 Tailscale, PC 에 OpenSSH 서버 | 명령만 치면 될 때 가장 가볍다 |
| RustDesk | 앱 | PC 에 호스트 | 화면 통째. 자체 서버도 가능 |

분기에 한 번 쓸 것이면 **Chrome 원격 데스크톱**이 손이 제일 덜 간다.
자주 명령만 칠 것이면 **Tailscale + SSH** 가 낫다.

---

## 4. 클라우드 세션에서 하지 말 것

- **`.env.local` 을 만들어 달라고 하지 말 것.** 키는 이 PC 와 Vercel 에만 둔다.
  이름만 보려면 `.env.example`.
- **`npm run dev` 로 확인하려 하지 말 것.** 키가 없어 시세가 빈다. 배포본을
  찌른다(§1).
- **`.cache/theme/` 를 읽는 스크립트를 돌리려 하지 말 것.** 파일이 없다.
  `scripts/theme/` 26개가 여기 해당한다.

## 5. 한 바퀴 예시

```
폰에서 signo-chi.vercel.app 을 보다가 이상한 것을 찾는다
  ↓
claude.ai/code 에서 signo 저장소를 연다
  ↓ "종목상세 1일 수익률이 위 등락률이랑 다른데 왜 그래"
원인을 찾아 고치고 npm run build 로 확인한 뒤 push
  ↓
Vercel 이 배포한다 (1~2분)
  ↓
폰 브라우저를 새로고침해서 눈으로 본다
```

PC 는 내내 꺼져 있어도 된다.
