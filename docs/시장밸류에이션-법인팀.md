# 버핏지수와 보완 지표 — 법인팀 전달

시장이 비싼지 싼지를 화면에 어떻게 담을 것인가에 대한 검토서다.

**법인팀은 네이버를 쓸 수 없으므로 계산은 SIGNO 가 돌리고 결과만 가져가면
된다.** 아래 §2 에 주소가 있다. 방법을 적어 둔 것은 값이 어떻게 나온
것인지 알고 쓰라는 뜻이지 직접 만들라는 뜻이 아니다.

---

## 1. 왜 버핏지수 하나로는 부족한가

버핏지수(시가총액 ÷ GDP)가 100%를 넘었다고 곧바로 거품이라 부를 수 없다.
분자와 분모의 성격이 다르기 때문이다.

**GDP는 매출, 주가는 이익이다.** GDP는 국내에서 창출된 부가가치의 합이고,
주가는 기업이 실제로 남기는 순이익과 앞으로의 성장을 본다. 이익 체질이
좋아지면 GDP가 그대로여도 시가총액은 정당하게 오른다.

**수출 기업의 해외 실적은 분자에만 잡힌다.** 반도체·자동차·배터리처럼
코스피를 끌고 가는 기업은 매출의 상당 부분을 밖에서 번다. 그 성과는
시가총액에 다 반영되지만 국내 GDP에는 온전히 안 잡힌다. 실적이 좋을수록
버핏지수가 착시로 높아지는 구조다.

**주주환원이 늘면 재평가가 일어난다.** 코리아 디스카운트로 눌려 있던 것이
자사주 소각·배당 확대로 풀리면 버핏지수는 자연스럽게 올라간다. 그것은
과열이 아니라 할인의 해소다.

정리하면 버핏지수는 **체중계**다. 체중이 늘었다는 사실은 알려 주지만
그것이 근육인지 지방인지는 말해 주지 않는다. 이익 기반 지표로 함께 봐야 한다.

## 2. SIGNO 가 주는 값

네이버 없이 쓸 수 있게 계산은 우리가 돌린다.

### 그대로 가져다 쓸 주소

```
GET https://signo-chi.vercel.app/api/market-value
```

여섯 시간 캐시다. 자주 불러도 부담이 없다. 응답은 시장마다 이렇게 온다.

```json
{ "data": {
    "시장들": [
      { "시장": "코스피",
        "선행per": 7.09, "후행per": 10.95, "per": 22.96,
        "pbr": 2.00, "종목": 738, "적자": 174,
        "시총": 5560, "컨센커버": 98.4, "해": 2025 },
      { "시장": "코스닥", "…": "같은 모양" }
    ],
    "버핏": null
} }
```

`버핏` 은 아직 `null` 이다 — 한국은행 ECOS 인증키를 넣으면 채워진다.
그때 이런 모양이 된다.

```json
"버핏": { "값": 202.4, "시총": 5988, "gdp": 2959, "gdp기간": "2025Q3~2026Q2" }
```

### 실측값 (2026-09-08)

|  | 코스피 | 코스닥 |
|---|---|---|
| **PER 선행** (컨센서스) | **7.09배** | **25.29배** |
| **PER 후행** (최근 4분기) | **10.95배** | **25.67배** |
| PER 연간 (2025 사업보고서) | 22.96배 | 16.69배 |
| PBR | **2.00배** | **1.68배** |
| ROE | 7.62% | 2.36% |
| 센 종목 | 738 (적자 174) | 1,489 (적자 661) |
| 시가총액 합 | 5,560조 | 428조 |
| 컨센서스 시총 커버 | 98.4% | 47.3% |
| 버핏지수 | *(키 대기)* | — |

### PER 이 셋인 이유

잣대가 달라 하나로 못 줄인다. 셋을 다 주니 쓰임에 맞게 고르면 된다.

| 필드 | 무엇 | 표본 |
|---|---|---|
| `선행per` | 애널리스트 컨센서스로 본 앞으로 1년 | 시총 상위 150 |
| `후행per` | 최근 4분기 실적(TTM) | 시총 상위 150 · 선행과 같은 표본 |
| `per` | 직전 사업연도(DART) · 흑자기업만 | 전 종목 |

**선행과 후행은 같은 표본이라 견주기 좋다.** 코스피가 10.95 → 7.09 라는
것은 시장이 이익이 크게 늘 것으로 본다는 뜻이다.

**`per` 은 표본이 넓은 대신 실적이 낡았다.** 2025년 사업보고서를 쓰기
때문이다. 삼성전자를 2025년 순이익 45.2조로 세면 PER 35배인데 최근
4분기로는 12배다. 반년 이상 뒤처진 값이므로 **최신 밸류에이션을 볼 때는
`후행per` 을 쓰는 편이 맞다.**

**코스닥 선행·후행은 시총의 절반만 덮는다**(`컨센커버` 47.3%). 애널리스트가
소형주를 안 보기 때문이다. 코스닥은 `per`(전 종목) 과 함께 봐야 한다.

재무는 2025년 연간, 시가총액은 실시간이다(= 후행 PER).

### PER 은 반드시 흑자기업만으로 세야 한다

이것이 이 계산에서 제일 중요한 판단이다.

```
코스닥   흑자만 16.82배   ·   적자 포함 71.56배
```

1,489종목 중 **665개가 적자**라 적자를 합계에 넣으면 분모가 깎여 72배가
나온다. 그 60배는 "코스닥이 비싸다" 가 아니라 **"적자 회사가 많다"** 는
뜻이다. PER 이라는 이름으로 부르면 읽는 사람을 속이게 된다.
KRX 공식 수치도 흑자기업 기준이다.

PBR 은 전체로 센다. 자본은 적자여도 남아 있다. 다만 **자본잠식(자본 ≤ 0)은
빼야 한다** — 음수 분모가 들어가면 값이 뒤집힌다.

### 어디서 오나

```
순이익 · 자본총계   DART fnlttSinglAcnt (주요계정)   한 번에 둘 다 나온다
시장 구분           DART company.json  corp_cls       Y=코스피 · K=코스닥
시가총액            네이버 시총 순위 목록              페이지당 100종목 · 두 시장 44쪽
```

재무는 종목당 DART 2회면 끝난다(**하루 한도 20,000건**). 시가총액은 매일
바뀌므로 굳히지 않고 한 시간 캐시로 그때그때 받는다.

### 시가총액을 셀 때 반드시 걸러야 할 것

**ETF·ETN 을 빼야 한다.** 네이버 코스피 목록 2,483건 중 주식은 944뿐이고
ETF 1,169 · ETN 370 이 섞여 있다. ETF 시총을 더하면 **그 안에 담긴 주식을
두 번 세는 것**이 된다. `stockEndType === "stock"` 인 것만 쓴다.

**우선주는 넣어야 한다.** 우선주도 그 회사에 대한 지분이므로 시장이 매긴
값의 일부다. KRX 통계도, 원조 버핏지수(Wilshire 5000)도 넣는다.

```
코스피   보통주 834종목 5,608조  ·  우선주 111종목 188조  ·  합 5,796조
코스닥   보통주 1,819종목 466조  ·  우선주 3종목 0조
```

**삼성전자우 하나가 160조**다. 코스피 시총의 3.2%가 우선주이므로 빼면
버핏지수도 PER·PBR 도 그만큼 낮게 나온다.

다만 분모(순이익·자본)는 **회사 하나당 한 번만** 세야 한다. 우선주 시총을
보통주 종목코드에 합쳐 두면 된다 — 우선주 코드는 보통주 코드의 끝자리를
5·7·9·K 로 바꾼 것이다.

```
005935 → 005930   삼성전자우 → 삼성전자
005387 → 005380   현대차2우B → 현대차
00104K → 001040   CJ제일제당우 → CJ
```

## 3. 버핏지수 — 코드는 붙었고 키만 기다린다

분자(시가총액 합)와 계산은 다 되어 있다. 분모인 GDP 만 한국은행 ECOS 에서
받아야 하는데 인증키 발급을 기다리는 중이다. 키가 들어오면 위 응답의
`버핏` 이 자동으로 채워진다 — **법인팀에서 할 일은 없다.**

키가 없는 동안에도 나머지 지표는 그대로 나온다(`버핏`만 `null`).

### 분모는 최근 4분기 합을 쓴다

처음에는 연간 명목 GDP 를 쓰려다 바꿨다. 분모가 직전 연도면 분자와 1년
넘게 어긋나고, 명목 GDP 는 해마다 5% 안팎 늘기 때문에 그만큼 지수가
부풀려진다.

```
2025 연간      2,677조   →   버핏지수 223.7%
최근 4분기 합   2,959조   →   버핏지수 202.4%      21%p 차이
```

```
ECOS  200Y105 / 1400   국내총생산(시장가격, GDP) · 원계열 · 명목 · 분기
                       2026Q2 까지 나와 있다
```

어긋남이 최대 세 달로 줄어든다.

**같은 표에 연간 자료가 섞여 온다.** 분기만 골라내지 않으면 연간값이 하나
끼어 합이 엉킨다. `/^\d{4}Q[1-4]$/` 로 거른다.

### 왜 명목인가

분자인 시가총액이 현재 가격이므로 분모도 현재 가격이어야 짝이 맞는다.
실질 GDP(2020년 연쇄가격)를 쓰면 그 사이 물가 상승분만큼 부풀려진다.

한국은행 분기 국민소득 **속보**에는 명목이 없다 — 마지막 달 실적을 다 못
받은 채 내기 때문에 실질만 낸다. 명목은 한 달 뒤 잠정치에서 나온다.

### 왜 예상 GDP 를 쓰지 않나

원조 버핏지수도 예상이 아니라 실현치를 쓴다.

**기관마다 다르다.** 한은·KDI·IMF·정부 전망이 제각각이라 하나를 고르는
순간 그 선택을 설명해야 한다.

**경고가 무뎌진다.** 버핏지수는 "증시가 실물보다 얼마나 앞서 있나" 를 재는
것인데, 분자에 이미 기대가 들어 있다. 분모에도 넣으면 같은 기대를 두 번
반영해 지표가 낮아진다.

**필요가 없다.** 최근 4분기면 실현치만으로 충분히 최신이다.

### 시가총액 범위를 밝혀야 한다

우리가 센 5,988조(코스피 5,560 + 코스닥 428)는 분류표에 든 회사 것만이다.
우선주와 ETF 처리는 §2 대로 바로잡았지만, 분류표에 없는 회사(신규상장·
리츠 일부)는 여전히 빠진다. 그래서 KRX 공식 시가총액보다 조금 작게 잡히고
버핏지수도 그만큼 낮다.

## 4. 보완 지표 — 무엇이 되고 무엇이 안 되나

| 지표 | 되나 | 왜 |
|---|---|---|
| **PBR - ROE** | **된다** | 순이익·자본을 이미 갖고 있다. ROE = Σ순이익 ÷ Σ자본 |
| **PER (후행)** | **된다** | 위 실측값 |
| **선행 PER** | **된다** | 처음에는 "컨센서스가 시장 전체를 못 덮는다" 고 봤는데 **종목 수로 판단한 것이 잘못이었다.** 시장 PER 은 시총 가중이라 시총 커버리지가 맞는 잣대다 — 코스피 98.4%. 위 `선행per` 이 그것이다 |
| **PEG** | 조건부 | 이익성장률이 필요한데 지금 가진 것은 매출성장률이다. DART 응답에 전기·전전기 금액이 같이 오므로 **저장만 하면 된다** — 다시 받을 필요는 없다 |

### PBR-ROE 를 권한다

버핏지수의 약점을 가장 직접적으로 메운다. **PBR 이 높은 것이 정당한가**를
ROE 가 답한다.

```
코스피   PBR 1.98배 · ROE 7.62%
코스닥   PBR 1.69배 · ROE 2.36%
```

같은 PBR 이라도 ROE 가 높으면 비싼 것이 아니다. 코스닥이 코스피보다 PBR 이
낮지만 ROE 는 3분의 1 수준이라는 점이 그대로 드러난다. 이 한 쌍이 "지수가
올랐는데 거품인가" 라는 물음에 버핏지수보다 나은 답을 준다.

## 5. 화면에 담을 때 — 지키기를 권하는 것

**공식치가 아님을 밝힐 것.** KRX 공식 수치와 다르다. 편입 범위가 전
상장사가 아니고, 기준 시점이 섞여 있기 때문이다(시총은 지금, 재무는 직전
사업연도). "자체 산출" 을 적어야 한다.

**몇 종목으로 셌는지 적을 것.** 코스피는 상장사 944 중 737을 셌다. 표본이
바뀌면 값도 바뀌므로 그 수를 보여 주는 편이 정직하다.

**적자기업 수를 함께 보일 것.** 코스닥 1,489 중 665 가 적자라는 사실 자체가
"PER 16.82배" 만큼 중요한 정보다.

**어느 PER 인지 적을 것.** 선행 7.09배와 연간 22.96배가 같은 화면에 이름
없이 뜨면 읽는 사람이 어느 쪽을 믿어야 할지 모른다. "컨센서스 기준" ·
"최근 4분기" 를 붙여야 한다.

**코스닥 선행·후행에는 커버리지를 붙일 것.** 시총의 47%만 덮는다.

**절대 수치를 단정하지 말 것.** 공식 수치가 아니라 우리 표본으로 센 값이다.
추세나 두 시장 비교로 읽는 편이 값 자체보다 안전하다.

## 6. 결론

버핏지수는 **버리지 말되 혼자 두지 말 것.** 악재가 왔을 때 변동성에
취약하다는 경고등으로는 여전히 유효하다. 다만 실적이 받쳐 주는 상승장에서는
높다는 이유만으로 거품이라 부를 수 없다.

지금 상태는 이렇다.

```
PER(선행·후행·연간) · PBR · ROE   ✅  /api/market-value 를 부르면 끝난다
버핏지수                          🔑  코드는 붙었다. ECOS 인증키만 기다린다
PEG                               ◻   DART 응답의 전기 금액을 저장하면 된다
```

**법인팀에서 지금 할 수 있는 것은 위 주소를 붙이는 것 하나다.** 버핏지수는
키가 들어오면 같은 주소에 저절로 채워지므로 화면만 미리 자리를 잡아 두면
된다(`버핏` 이 `null` 이면 감추면 된다).

계산 방법과 함정(적자 처리·자본잠식·ETF 제외·우선주 합산)은 SIGNO 쪽에
코드로 정리되어 있다. 다만 **법인팀은 네이버를 못 쓰므로 직접 만들 것이
아니라 §2 의 주소를 부르면 된다.** 값이 어떻게 나온 것인지만 알고 쓰면
충분하다.
