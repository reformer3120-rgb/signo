# 테마 등락률 그래프 — 어떻게 만드나

테마 상세의 그래프(테마·대장주·코스피·코스닥 넷을 겹친 것)를 만드는 방식.
구현은 `src/lib/ownTheme.ts` 의 `buildChart`, 라우트는
`src/app/api/themes/[no]/chart/route.ts`.

옮겨 심는 쪽에서 같은 그래프를 만들려면 이 문서만 보면 된다.

---

## 1. API

```
GET /api/themes/{id}/chart?days=90
```

`days` 는 20~250 사이로 자른다(기본 60). 화면은 1개월(30)·3개월(90)·
6개월(180)을 쓴다.

```json
{
  "data": [
    { "d": "20260417", "v": 0,     "lead": 0,     "ks": 0,    "kq": 0    },
    { "d": "20260420", "v": -0.26, "lead": -0.34, "ks": 0.44, "kq": 0.41 },
    { "d": "20260421", "v": 0.93,  "lead": 4.37,  "ks": 3.17, "kq": 0.77 }
  ],
  "leadName": "한국타이어앤테크놀로지",
  "days": 90
}
```

| 필드 | 뜻 |
|---|---|
| `d` | 날짜 `yyyymmdd` |
| `v` | 테마 — 첫날을 0 으로 둔 누적 등락률 % |
| `lead` | 대장주 (시총 1위) |
| `ks` | 코스피 |
| `kq` | 코스닥 |
| `leadName` | 대장주 이름 — 범례에 쓴다 |

**넷 다 첫날 0 에서 시작하는 누적 수익률이라 그대로 그리면 된다.**
축 맞추기나 정규화를 따로 할 필요가 없다.

`lead`·`ks`·`kq` 는 `null` 일 수 있다(그 계열을 못 받은 경우). 그 계열만
빼고 그린다.

---

## 2. 테마 지수를 어떻게 내나

### 2.1 단순 평균이어야 한다

```
날마다  구성종목 등락률의 단순 평균  →  이어 붙여 누적
```

**시총 가중으로 만들면 안 된다.** 화면 머리의 테마 등락률이 단순 평균이라,
가중으로 그리면 숫자와 그래프가 어긋난다. 요약 줄에 시총가중(`weighted`)이
따로 있는 것과는 별개다 — 그건 견주기용 숫자고, 그래프는 화면의 대표 숫자와
같은 방식이어야 한다.

### 2.2 시총 상위 20종목만 쓴다

전 종목 일봉을 받으면 무겁다. 74종목짜리 테마면 74번을 두드려야 한다.

```
시총 = 현재가 × 상장주식수  로 줄 세워 상위 20개
테마의 움직임은 큰 종목이 좌우하고, 20개면 모양이 충분히 잡힌다
```

대장주(`lead`)는 이 줄에서 1위인 종목이다.

### 2.3 하루 앞 종가가 더 필요하다

등락률을 만들려면 전날 종가가 있어야 하므로 `days + 1` 개를 받는다.

### 2.4 버리는 값 둘

**가격제한폭 밖** — `|등락률| > 30.5%` 는 시세가 아니라 데이터 오류다.
목록 화면과 같은 기준으로 버린다. (헝셩그룹이 +400% 로 들어와 화장품
브랜드 테마 평균이 +22% 가 된 적이 있다.)

**그날 종목이 너무 적을 때** — 상위 20종목 중 절반(최소 3개)이 안 되면
그 날짜는 건너뛴다. 두세 종목만으로 낸 평균은 튄다. 신규 상장이나 거래정지가
섞이면 이런 날이 생긴다.

### 2.5 첫날은 넷 다 0

```
첫 점       v = lead = ks = kq = 0
그다음부터   누적 = 누적 × (1 + 그날 등락률 / 100)
```

겹쳐 놓고 견주려면 같은 자리에서 출발해야 한다.

## 3. 시세를 어디서 받나

### 3.1 종목 일봉

```
KIS  inquire-daily-itemchartprice
```

**한 번에 100행까지만 준다.** 180일치를 받으려면 날짜를 거슬러 올라가며
여러 번 불러 이어 붙여야 한다(`dailyBars` 가 그 일을 한다).

동시 5종목씩 받는다. 한 종목이 실패해도 평균은 서므로 그냥 건너뛴다.

### 3.2 지수 일봉

```
KIS  FHKUP03500100     코스피 0001 · 코스닥 1001
```

**한 번에 50행까지만 준다.** 종목 일봉보다 더 짧게 끊기므로 페이지를 더 많이
돌아야 한다. 값은 `bstp_nmix_prpr` 필드다.

코스콤으로 옮길 때는 지수 시계열을 주는 엔드포인트를 찾아 이 자리에 끼우면
된다. 없으면 `ks`·`kq` 를 `null` 로 두고 테마와 대장주만 그려도 화면은
성립한다.

---

## 4. 캐시

```
키     ownTheme:chart:v5:{id}:{days}
기간   12시간
```

하루에 점 하나가 늘어날 뿐이라 오래 잡아도 된다. 장중에 다시 계산할 값이
아니다.

라우트는 `maxDuration = 60` 이다. 20종목 × 여러 페이지를 받으므로 첫 호출이
5~6초 걸린다. 두 번째부터는 캐시라 즉시 나온다.

---

## 5. 화면에서 지킬 것

**범례에 값을 같이 적는다.**

```
── 테마 +5.39%   ── 한국타이어앤테크놀로지 -7.52%
── 코스피 -21.42%   ── 코스닥 -20.13%          6/4 ~ 8/28
```

넷을 겹쳐 놓기만 하면 어느 선이 무엇인지 못 읽는다. 마지막 값을 범례에
적으면 선을 따라가지 않아도 결과가 보인다.

**기간 버튼은 1개월 · 3개월 · 6개월.** 그보다 길면 테마 구성이 바뀌었을
수 있어(분기에 한 번 갱신) 뜻이 흐려진다.

---

## 6. 이 그래프가 왜 있나

타이어 테마를 보면 이렇다.

```
테마 +5.39%      대장주(한국타이어) -7.52%      코스피 -21.42%
```

**대장주는 빠졌는데 테마는 올랐다.** 나머지 종목이 끌었다는 뜻이고, 이건
숫자 하나로는 절대 안 보인다. 테마 화면에서 이 그래프를 빼면 남는 것은
종목 목록뿐이다.
