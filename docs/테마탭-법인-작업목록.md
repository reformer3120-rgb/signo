# 테마 탭 — 법인 앱에 반영할 것

두 화면을 대조해 무엇을 어느 쪽으로 맞출지 정한 결과다(2026-08-31).
**법인 앱이 손대야 할 것만** 적었다. 그대로 두는 것은 "유지" 로 표시했다.

정한 것 셋
```
1  목록 화면   기준일·설명위치·테마별설명·리더종목은 법인 것을 쓴다
              대분류 접기·필터정렬·검색범위는 SIGNO 것을 쓴다
2  상세 화면   SIGNO 것으로
3  종목 카드   사업설명 · 시총 · 매출성장률 · 영업이익률 · PER
              + 최근 수급 우수주체
```

기준 API 는 SIGNO 것이고, 응답은 2026-08-31 에 실제로 받은 값이다.

---

## 1. 목록 화면 — 셋을 더한다

법인 앱이 이미 가진 것(**유지**) — 기준일 `2026-08-28 기준` · 머리의 설명
`한 종목은 한 테마에만 들어갑니다` · 테마별 설명 한 줄 · 리더 3종목 등락률.

### 1.1 대분류로 접는다

지금은 91개 테마가 전부 펼쳐진 긴 스크롤이다. 12개 대분류로 접고, 접힌
줄에 **등락률·막대·종목수**를 적는다.

```
▶ 소비재      테마 14 · 324종목      ▬▬▬▬▬  +1.61%
▼ 자동차      테마 3 · 85종목        ▬▬▬▬▬  +1.58%
    타이어    타이어와 그 원부자재   6   금호타이어 +4.36% · …   ▬  +2.37%
    완성차    자동차를 직접 만들어…   5   대원강업 +4.69% · …     ▬  +1.79%
▶ 전자부품    테마 3 · 95종목        ▬▬▬▬▬  +1.10%
```

**이게 이 목록의 핵심이다.** 접힌 12줄만 보면 오늘 어디가 움직이는지 끝난다.
지금은 그걸 알려면 91개를 다 스크롤해야 한다.

```
막대   상승 종목 수 대 하락 종목 수 비율 (up / down)
등락률  그 대분류에 속한 종목 전체의 단순 평균
```

`GET /api/themes` 가 테마마다 `group` `chg` `up` `down` `count` 를 주므로
대분류 값은 그것을 묶어 내면 된다. 새 API 는 필요 없다.

### 1.2 필터와 정렬

```
[전체] [상승] [하락]        [등락] [종목수] [이름]
```

91개에서 오늘 오른 것만 보고 싶을 때가 많다. 두 줄이면 된다.

### 1.3 검색이 설명까지 훑게

```
지금   테마명 · 종목명
후     테마명 · 종목명 · 테마 설명 · 편입 사유 문장
```

"양극재" 로 찾으면 테마 이름에 없어도 그 낱말이 든 종목이 걸린다.
편입 사유는 `GET /api/theme-index` 가 테마별 구성종목 이름을 주고, 설명은
테마 목록의 `hint` 에 있다.

---

## 2. 상세 화면 — 넷을 더한다

지금은 구성종목 목록만 나온다. 그 위에 넷을 얹는다.

### 2.1 요약 줄

```
평균 +2.37%    시총 가중 +1.68%       6종목 · 상승 6 · 보합 0 · 하락 0
▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬
```

평균과 시총가중을 같이 보여주면 **소형주가 끌었는지 대형주가 끌었는지**가
바로 갈린다. 등락률 하나만 있으면 그걸 못 가른다.

`GET /api/themes/{id}` → `chg` `weighted` `count` `up` `flat` `down`

### 2.2 한 줄 해석

```
소형주가 끌었다 — 시총으로 가중하면 0.69%p 낮다.
```

위 두 숫자의 차이를 말로 푼다. `chg - weighted` 로 만든다.

```
차이 > 0     소형주가 끌었다 — 시총으로 가중하면 N%p 낮다.
차이 < 0     대형주가 끌었다 — 시총으로 가중하면 N%p 높다.
차이 ≈ 0     (적지 않는다)
```

### 2.3 무엇을 묶었나

```
무엇을 묶었나   타이어와 그 원부자재
```

목록 화면의 `hint` 와 같은 값이다. 상세에서도 한 번 더 밝힌다.

### 2.4 등락률 그래프 — 가장 크다

```
3개월 누적 +5.39%                          [1개월] [3개월] [6개월]
  ── 테마 +5.39%
  ── 한국타이어앤테크놀로지 -7.52%   (대장주)
  ── 코스피 -21.42%
  ── 코스닥 -20.13%                6/4 ~ 8/28
```

**넷을 한 판에 겹치는 것이 핵심이다.** 타이어를 보면 대장주는 -7.52% 인데
테마는 +5.39% 다 — 대장주 빼고 나머지가 끌었다는 뜻이고, 이건 그래프 없이는
안 보인다.

`GET /api/themes/{id}/chart?days=90` 한 번이면 네 계열이 다 온다.

```json
[{ "d": "20260417", "v": 0, "lead": 0, "ks": 0, "kq": 0 },
 { "d": "20260420", "v": -0.26, "lead": -0.34, "ks": 0.44, "kq": 0.41 }]
```

`v` 테마 · `lead` 대장주 · `ks` 코스피 · `kq` 코스닥. 넷 다 첫날을 0 으로
맞춘 누적 수익률이라 그대로 그리면 된다. `days` 는 30 / 90 / 180.

**만드는 방식은 `테마차트-만드는법.md` 에 따로 적었다** — 왜 단순 평균이어야
하는지, 왜 시총 상위 20종목만 쓰는지, KIS 가 100행·50행씩만 준다는 것,
버리는 값 둘(가격제한폭 밖 · 그날 종목이 너무 적을 때)까지.
직접 만들 것이 아니라 API 를 그대로 쓸 거면 위 계약만 보면 된다.

### 2.5 구성종목 정렬

```
[등락순] [시총순] [이름순]
```

시총순이 있으면 "이 테마의 대장주가 누구냐" 를 바로 본다.

## 3. 종목 카드 — 셋을 더한다

지금 있는 것(**유지**) — 종목명 · 가격 · 등락률 · 사업설명 문장 ·
매출성장률 · 영업이익률.

**사업설명은 바꿀 것이 없다.** 지금 쓰는 문장이 SIGNO 의 `why` 와 같은
데이터다(대원미디어의 그 긴 문장까지 똑같다). 2,497종목 중 2,253종목(90%)에
있고, 없는 종목은 그 줄만 비운다.

### 더할 것

```
시총                  2.13조         ← 새로
PER                   6.1배          ← 새로
최근 수급 우수주체       기관 매수우위    ← 새로
```

완성된 모양:

```
금호타이어                                          7,420  +4.36%
타이어를 제조·판매하는 타이어전문기업으로, 중국 더블스타가 최대주주다.
  시총 2.13조 · 매출성장 +3.73% · 영업이익률 +12.25% · PER 6.1배
  기관 매수우위
```

### 어디서 받나

`GET /api/themes/{id}` 의 `stocks[]` 에 다 들어 있다.

```json
{
  "code": "073240", "name": "금호타이어",
  "why": "타이어를 제조·판매하는 타이어전문기업으로, 중국 더블스타가 최대주주다.",
  "biz": ["타이어"],
  "price": 7420, "chg": 4.36,
  "cap": 21300,          // 억원
  "per": 6.1,
  "growth": 3.73,        // 매출액증가율 % (DART 확정 실적)
  "opm": 12.25,          // 영업이익률 %
  "bias": "기관"          // 최근 5거래일 매수 우위 주체
}
```

### 수급 우수주체는 새 데이터다

`bias` 는 **최근 5거래일 순매수 합이 가장 큰 주체**다. `개인` · `외국인` ·
`기관` · `-` 중 하나이고, `-` 는 셋 다 순매도라 우위가 없다는 뜻이므로
화면에 적지 않는다.

**종목마다 부르면 안 된다.** 74종목짜리 테마에서 수십 번을 두드리게 된다.
SIGNO 는 지표 크론이 하루 한 번 모아 두고 화면은 읽기만 한다.

```
크론      종목별로 최근 5거래일 투자자 순매수를 받아 우위 주체를 계산해 저장
화면      쌓인 것만 읽는다
```

크론이 아직 안 훑은 종목은 `null` 로 오고, 그 조각만 빠진 채 나머지는
정상으로 보인다. **0 이나 "—" 로 채우지 말 것.**

### 낱말 칩(`biz`)은 안 쓴다

`biz` 는 사업설명 문장에서 품목만 뽑아 둔 낱말이다. 사업설명 문장을 쓰기로
했으므로 이 카드에서는 필요 없다. 문장이 없는 10% 종목에서만 대신 쓰면 된다.

## 4. 순서

앞이 값싸고 눈에 띄는 변화가 크다.

```
1  종목 카드에 시총·PER 더하기      /api/themes/{id} 에 이미 온다      반나절
2  요약 줄 + 한 줄 해석             같은 응답의 weighted·up·flat·down   반나절
3  무엇을 묶었나 + 구성종목 정렬     hint 는 이미 온다                  반나절
4  대분류 접기 + 등락률·막대         group 으로 묶어 낸다               1~2일
5  필터·정렬 · 검색 범위 넓히기                                        1~2일
6  등락률 그래프                    /chart 한 번                      2~3일
7  수급 우수주체                    크론이 먼저 필요하다                1주 이상
```

1~3 은 지금 오는 응답만으로 된다. 새로 부를 것이 없다.

**7 만 성격이 다르다.** 투자자 수급을 종목별로 모으는 크론을 세워야 한다.
없으면 이 한 줄 때문에 화면이 느려진다. 1~6 을 먼저 내보내고 7 은 뒤에
붙여도 된다.
